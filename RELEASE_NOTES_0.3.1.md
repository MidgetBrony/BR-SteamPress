# BR-SteamPress 0.3.1

- First public Boxmate release of The Boxroom Press.
- Publishes recent Steam news and configured RSS or Atom feeds as dated, readable magazine issues.
- Generates BOXROOM-styled covers and CBZ pages, then refreshes BR-BookSystem automatically.
- Keeps feed URLs and publication settings local to the player's BOXROOM installation.

Validation: Release build and package verification. Live BOXROOM reading and controller acceptance were completed during local development; public-install verification is performed for this release.
